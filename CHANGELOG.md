# Changelog

### 2026-07-25

- Initial implementation of the feedback module for OXID eShop
- Feedback form in the backend header and as a storefront button, each toggleable on its own
- Screenshot support via clipboard paste with preview and per-image removal
- Ticket title and description generated by OpenAI, with the original report always kept in the issue
- GitLab issue creation including screenshot uploads and optional assignee
- Environment data at the issue: page, referrer, browser, viewport, shop, theme, active modules, versions
- Optional bot protection through tabslTurnstile, without a hard dependency
- Twelve module settings, no project-specific defaults
- Technical failures are written to the shop log with a `[tabslFeedback]` prefix, without report text or credentials
